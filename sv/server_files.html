💾 Quản Lý File Jar & Lệnh Khởi Động Server

Lưu trữ thông tin tệp cốt lõi và câu lệnh khởi động máy chủ Minecraft 1.21.4.

📦 Thông Tin Tệp Lõi (Server Jar)

Tên tệp: server.jar (PaperMC 1.21.4)
Trạng thái: Đã sẵn sàng
Phiên bản Java yêu cầu: Java 21
Đường dẫn lưu trữ trên GitHub/Host:
/sv/jar/server.jar

⚡ Lệnh Khởi Động (Start Command)

Sử dụng câu lệnh dưới đây để chạy máy chủ với phân bổ RAM tối ưu:

java -Xms2G -Xmx4G -XX:+UseG1GC -jar server.jar nogui
