⚡ Quản Lý Server Minecraft 26.2 (4GB RAM)

📖 Hướng dẫn nhanh các bước tạo Server:

  1. Cài đặt Java: Máy tính cần cài sẵn Java mới nhất để chạy phiên bản 26.2.
  2. Tạo thư mục: Tạo một thư mục trống mới trên máy (ví dụ: ServerMinecraft).
  3. Tải nhân Server: Bấm nút tải nhân Paper 26.2 bên dưới và cho file vào thư mục đó.
  4. Đổi tên file: Đổi tên file vừa tải thành chính xác: paper.jar.
  5. Tạo file khởi động: Tạo file văn bản, dán mã khởi động 4GB RAM bên dưới vào, lưu lại với tên start.bat.
  6. Chạy Server: Click đúp vào start.bat. Khi báo lỗi EULA, mở file eula.txt đổi thành eula=true rồi chạy lại lần nữa!

📥 Tải xuống nhân Paper 26.2:

👉 Tải trực tiếp Paper 26.2 (.jar)
Link tải trực tiếp bản ổn định của phiên bản 26.2

💻 Mã Khởi Động Server (Cấu hình tối ưu 4GB RAM):

Dành cho Windows (Dán vào file start.bat):

java -Xms2G -Xmx4G -XX:+UseG1GC -jar paper.jar nogui pause

Dành cho Linux / VPS / Pterodactyl Panel:

java -Xms2G -Xmx4G -XX:+UseG1GC -jar paper.jar nogui
💡 Lưu ý: -Xms2G (RAM tối thiểu 2GB), -Xmx4G (RAM tối đa 4GB). Đảm bảo file trong thư mục tên đúng là paper.jar.
