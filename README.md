# Voxel Tactical Battle Royale (Project MM)

Một thể loại game 3D hoàn toàn mới: Kết hợp xây khối chiến thuật (Voxel) và bắn súng sinh tồn góc nhìn thứ 3.

## 🎮 Tính năng cốt lõi
- **Di chuyển 3D:** Xoay camera, chạy, nhảy.
- **Voxel Tactics:** Đặt khối nẩy (Jump Voxel) và khối chắn đạn nhanh.
- **Web Play:** Chơi trực tiếp trên trình duyệt web thông qua GitHub Pages.

## 🚀 Trạng thái dự án
Dự án đang trong giai đoạn phát triển thử nghiệm (Prototype).
